# حزم الإصدار العربي

الإصدار: `1.12.1-arabic.1`، نسخة تجريبية من فرع `feature/arabic-rtl` دون دمج في `main`.

مصدر الحزم المختبر هو commit `efa23eca8b24b7e187e5c7f1441613b9943ba14a`. تغييرات التوثيق والنشر اللاحقة لا تغيّر كود التطبيق أو الاختبارات أو محركات التحويل في هذه الحزم.

## التنزيل

[صفحة الإصدار](https://github.com/86msa/Filee/releases/tag/arabic-v1.12.1-arabic.1)

| النظام | المعمارية | الحزمة |
|---|---|---|
| Windows 10 / 11 | x64 | `Filee-1.12.1-arabic.1-win-Setup.exe` |
| Windows 10 / 11 | x64 | `Filee-1.12.1-arabic.1-win-Portable.zip` |
| Linux، Ubuntu 22.04 فأحدث | x64 | `Filee-1.12.1-arabic.1-linux-x64.tar.gz` |
| Linux، Ubuntu 22.04 فأحدث | ARM64 | `Filee-1.12.1-arabic.1-linux-arm64.tar.gz` |
| macOS 14 فأحدث | Intel | `Filee-1.12.1-arabic.1-osx-x64.tar.gz` |
| macOS 14 فأحدث | Apple Silicon | `Filee-1.12.1-arabic.1-osx-arm64.tar.gz` |

تحتوي حزم Linux وmacOS على تعليمات وسكربتات التثبيت والإزالة. جميع الحزم تتضمن بيئة .NET، ولا تحتاج إلى تثبيت SDK. تُنزّل المحركات الكبيرة من داخل التطبيق كالمعتاد.

تحفظ صفحة الإصدار `SHA256SUMS.txt` للتحقق من الحزم الست، و`VALIDATION.json` لنتائج الاختبارات والاختبارات المتجاوزة لكل منصة، و`Screenshots-Arabic.zip` لصور اختبارات الواجهة العربية عبر المنصات.

## فحوص البناء والتشغيل

نجح [بناء المنصات الخمس واختبارها](https://github.com/86msa/Filee/actions/runs/39231602605) على Windows x64، وLinux x64 وARM64، وmacOS Intel وApple Silicon. شغّلت كل منصة مجموعات `Core` و`Platform` و`Engines` و`Cli` و`App`، بما فيها اختبارات العربية وRTL والعرض. لا تُعدّ الاختبارات المتجاوزة نجاحاً؛ تحفظ أسماؤها في `VALIDATION.json`.

| المنصة | ناجح | إخفاق | متجاوز |
|---|---:|---:|---:|
| Windows x64 | 1641 | 0 | 66 |
| Linux x64 | 1628 | 0 | 77 |
| Linux ARM64 | 1626 | 0 | 79 |
| macOS Intel | 1623 | 0 | 82 |
| macOS Apple Silicon | 1623 | 0 | 82 |
| مجموع التنفيذات عبر المنصات | 8141 | 0 | 386 |

هذه تنفيذات متكررة للاختبارات على أنظمة مختلفة وليست 8141 حالة مستقلة. يستبعد مسار Unix في المشروع أيضاً حالتي Windows `ExplorerMenuTests.Every_native_import_exists_in_the_dll_it_names` و`ExplorerMenuTests.Reading_the_registered_package_never_throws` بمرشح قبل التنفيذ؛ لا تظهران ضمن نتائج TRX المتجاوزة على Unix. تتضمن التجاوزات الأخرى المحركات الاختيارية غير المثبتة، وGPU، والتكاملات المشروطة بنظام التشغيل؛ الأسماء الكاملة محفوظة في ملف التحقق.

نجحت فحوص أرشيفات Unix وبصماتها، وتشغيل CLI والمحركات المضمّنة، والتحويل TXT → HWPX → HWP → PDF، وتشغيل التطبيق وإغلاقه. نجح فحص توقيع حزم macOS. بُني rhwp من المصدر المثبت على Ubuntu 22.04 للمعماريتين؛ اجتازت جميع ملفات ELF حد glibc 2.35، واجتازت حزمتا Linux أيضاً تشغيل CLI والمحركات والواجهة على Ubuntu 22.04 فعلياً في CI.

في البيئة المحلية اختُبرت حزمة Linux مستقلة: تشغيل الواجهة العربية وحفظ صورة وإغلاقها، والتثبيت والإزالة داخل Ubuntu 22.04، والحفاظ على النص واسم الملف العربي في DOCX → TXT، وعرض PDF عربي إلى PNG. حفظت نتائج هذه الفحوص تحت `artifacts/arabic-release-smoke/` و`build/.cache/arabic-release-conversions/`. تفاصيل فحوص المحتوى وحدود محركات المستندات في [تقرير التعريب](ARABIC-RTL.md).

نجحت [خطوة النشر والتحقق من التقارير والصور](https://github.com/86msa/Filee/actions/runs/39234987587). نُزّلت الحزم الست المنشورة إلى `Releases/` وطوبقت بصماتها مع `SHA256SUMS.txt`؛ نجحت جميعها. أُعيد فحص أرشيف Linux x64 المنشور نفسه على الجهاز الحالي وداخل Ubuntu 22.04 دون اتصال بالشبكة: تشغيل CLI وrhwp و7-Zip، وسلسلة التحويل، وتحميل مكتبة خطاف X11. تحفظ النسخة المفكوكة محلياً تحت `artifacts/arabic-release-final-smoke/`.

## الملفات المضافة أو المعدلة لأجل الحزم

- `.github/workflows/arabic-builds.yml`: بناء Windows Setup وPortable، واستدعاء بناء Linux وmacOS على الأجهزة الأصلية، وجمع الحزم الست بعد نجاح الاختبارات والتحقق من SHA-256 في مسودة إصدار.
- `.github/workflows/publish-arabic.yml`: نشر نسخة تجريبية فقط بعد إثبات نجاح بناء commit المصدر، وإعادة التحقق من الحزم، وتجميع تقارير TRX وصور العربية. وسم النشر `publish-arabic-v<version>`؛ يمكن إضافة `+retry.N` لإعادة المحاولة دون تغيير وسم المصدر.
- `build/build-installer.ps1` و`installer/Filee.iss`: قبول رقم إصدار تجريبي، وتمرير الجزء الرقمي إلى حقل إصدار EXE الذي لا يقبل لاحقة SemVer. يبقى اسم الحزمة وإصدار التطبيق كاملين.
- `docs/ARABIC-RELEASE.md`: ملاحظات الإصدار وتعليمات اختيار الحزمة وحدود التحويل والتوقيع.

تُستثنى تغييرات التوثيق وملف نشر الإصدار فقط من إعادة بناء التطبيق. يظل تعديل كود التطبيق أو الاختبارات أو سكربتات بناء الحزم خاضعاً للبناء والاختبارات.

## حدود التحقق والتوزيع

حزم Windows غير موقّعة بشهادة ناشر تجارية، وحزم macOS موقعة ad-hoc ولم توثّق لدى Apple. يبقى دعم Linux وmacOS تجريبياً وفق المشروع الأصلي.

لم أنفّذ تثبيت Windows تفاعلياً على جهاز مستخدم، أو فحص قارئ الشاشة وعلبة النظام والسحب من مدير الملفات على أجهزة Windows وmacOS فعلية. اختبارات الواجهة الآلية على هذه الأنظمة تستخدم Avalonia Headless؛ فحص بدء التطبيق الأصلي منفصل عنها. لا يضمن نجاح اختبارات التحويل سلامة جميع المستندات العربية؛ تبقى ملاحظات DOCX/PDF في تقرير التعريب وملاحظات الإصدار سارية.

عوامل CI كانت `windows-latest` وUbuntu 24.04/22.04 وmacOS 15؛ لم يجر فحص يدوي على Windows 10/11 أو macOS 14. فحص سطح مكتب Linux كان على X11، ولا يثبت سلوك جلسة Wayland الفعلية.

تبقى الإخفاقات الثلاثة المسجلة في البيئة المحلية الأولى مرتبطة بمسارات LibreOfficeDev/Ghostscript كما يشرح تقرير التعريب؛ لم تُضعف تأكيداتها لإنتاج الحزم. نتائج CI تخص الأدوات المتاحة على كل عامل بناء، والاختبارات المتجاوزة موثقة منفصلة.
