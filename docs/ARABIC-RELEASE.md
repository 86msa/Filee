# Filee 1.12.1-arabic.1

نسخة تجريبية لدعم العربية واتجاه الواجهة RTL، مبنية من فرع `feature/arabic-rtl`.

- ترجمة جميع مفاتيح الواجهة الـ696، مع التبديل المباشر بين العربية واللغات الحالية.
- اتجاه ومحاذاة ديناميكيان، وخط Noto Sans Arabic المضمّن، وتحسين عرض أسماء الملفات والنص المختلط.
- يمكن اختيار «العربية» من الإعدادات؛ تُكتشف لغة النظام العربية تلقائياً أيضاً.

## حزم التثبيت

| النظام | المعمارية | الحزمة |
|---|---|---|
| Windows 10 / 11 | x64 | `Filee-1.12.1-arabic.1-win-Setup.exe` أو `Filee-1.12.1-arabic.1-win-Portable.zip` |
| Linux، Ubuntu 22.04 فأحدث | x64 / ARM64 | `Filee-1.12.1-arabic.1-linux-<arch>.tar.gz` |
| macOS 14 فأحدث | Intel / Apple Silicon | `Filee-1.12.1-arabic.1-osx-<arch>.tar.gz` |

حزم Linux وmacOS تتضمن تعليمات التثبيت وسكربتات التثبيت والإزالة. تُضمّن بيئة .NET، فلا يلزم تثبيت SDK. تُنزّل محركات التحويل الكبيرة بشكل منفصل من التطبيق. تحقّق من التنزيل باستخدام `SHA256SUMS.txt`.

حزم macOS التجريبية تستخدم توقيع ad-hoc؛ لم توثّق لدى Apple. دعم Linux وmacOS ما زال تجريبياً حسب المشروع الأصلي.

## ملاحظات التحويل

تعريب الواجهة لا يغيّر قدرات محركات المستندات. أظهر الفحص أن المسار المدمج DOCX → PDF وقراءة PDF → DOCX قد يفسدان ترتيب العربية أو شكل حروفها. أعطى خيار LibreOffice الموجود في التطبيق نتيجة عربية سليمة لعينة DOCX → PDF المختبرة؛ يجب مراجعة المستند الناتج.

توجد تفاصيل الاختبارات والصور والقيود في `docs/ARABIC-RTL.md` داخل المصدر. تبقى هذه النسخة تجريبية لحين التحقق من الحزم على الأنظمة المستهدفة.
